Target: надёжность клиента после выдачи

Задание scoring · snapshot 2025-05-31 · файлы: scoring_target.csv, scoring_target_full.csv, scoring_target_by_issue_month.csv

ПРАВИЛО

target = 1, если за первые 6 месяцев после issue_date максимальный DPD по платежам ≥ 30 дней. Иначе 0.

DPD = paid_date − due_date; если не оплачено → 2025-05-31 − due_date. В выборку только договоры с закрытым окном: issue_date + 6 months ≤ 2025-05-31.

Почему такое правило

  • 6 месяцев — горизонт, за который успеваем увидеть ранний дефолт, и ещё остаётся история для out-of-time.
  • DPD30+ — банковский стандарт «серьёзной» просрочки; не штрафуем за опоздание на пару дней.
  • Цензура — свежие договоры (дек 2024 – май 2025) не размечаем: исход ещё неизвестен.
  • Target только у одобренных (есть договор). Отказы — для анализа политики, не для лейбла.

SQL (основной)

WITH pay AS (
  SELECT contract_id, due_date,
         CASE WHEN paid_date IS NOT NULL THEN paid_date - due_date
              ELSE DATE '2025-05-31' - due_date END AS dpd
  FROM scoring_payments
),
obs AS (
  SELECT ct.application_id, ct.client_id, a.decision_date,
         COALESCE(MAX(GREATEST(pay.dpd,0)) FILTER (
           WHERE pay.due_date <= ct.issue_date + INTERVAL '6 months'
             AND pay.due_date <= DATE '2025-05-31'
         ), 0) AS max_dpd_6m
  FROM scoring_contracts ct
  JOIN scoring_applications a USING (application_id)
  LEFT JOIN pay ON pay.contract_id = ct.contract_id
  WHERE ct.issue_date + INTERVAL '6 months' <= DATE '2025-05-31'
  GROUP BY 1,2,3, ct.issue_date
)
SELECT application_id, client_id, decision_date,
       CASE WHEN max_dpd_6m >= 30 THEN 1 ELSE 0 END AS target
FROM obs;
